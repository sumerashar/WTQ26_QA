# Explanation of Formate of Test_Detail_Sheet.ods

Got it, simple and straight to the point:

Test_Id`: Test number (*e.g., `TC-001 ).

Module`: Feature or page you are testing (*e.g., `Login Page ).

Test_Type`: How it was tested (*e.g., `Manual` or `Automation).

Execution Status : Result of the test (*e.g., `PASS` or `FAIL).

Severity : How bad the bug is if it fails (*e.g., `High`, `Medium` or `Low `).
